Yeet Documentation & API Reference

Wayland-native interactive stream throwing system and 2D physics overlay for OBS Studio
KDE 6 & Wayland Native: Yeet is designed according to modern KDE Human Interface Guidelines (HIG) with Qt6, providing low-latency Matter.js physics and Web Audio playback for livestreamers and VTubers on Linux.

🎯 System Overview

Yeet allows streamers to set up 2D collision targets (around their VTuber avatar or webcam frame), throw items using chat commands or channel points, and display dynamic physics impacts inside OBS Studio without third-party cloud dependencies.

🎥 OBS Studio Integration

The visual physics simulation and procedural audio run via an HTML5 canvas inside OBS Studio.

Browser Source Setup Instructions
  1. Open OBS Studio.
  2. In your streaming scene's Sources dock, click + and choose Browser.
  3. Set the Source Name to Yeet Physics Overlay.
  4. Configure the properties:
    • URL: http://127.0.0.1:49122/overlay
    • Width & Height: 1920 × 1080 (or match your canvas base resolution).
    • Custom frame rate: Checked, set to 60 FPS.
    • Shutdown source when not visible: UNCHECKED (crucial to maintain WebSocket connection).
    • Refresh browser when scene becomes active: UNCHECKED.
  5. Click OK and click Test Throw in Yeet to verify!

✨ Adding Custom Items & Groups

Streamers can add an unlimited number of custom throwable items with their own images and sound effects:

  • Supported Image Formats: SVG, PNG, WebP, GIF.
  • Supported Audio Formats: Built-in procedural synths (squish, bonk, thud, pop, clang) or custom audio files (.wav, .mp3, .ogg).
  • Group Tags: Assign any arbitrary string (e.g. pokemon, spooky, weapons) in the GUI or config.json.

🎯 Collision Targets & Relative Coordinates

Targets define the solid obstacle geometries in the OBS overlay where projectiles bounce and trigger webhooks. All coordinates use normalized relative units (0.0 to 1.0), ensuring target boundaries stay aligned across 1080p, 1440p, 4K, or vertical mobile streams.

Target Shape Type Key Key Parameters Best Used For
Capsule / Pill capsule x, y, width, height, rotation VTuber torso, arms, legs, elongated avatars
Circle / Ellipse circle x, y, radius, rotation VTuber head, circular webcams, badges, mascots
Rectangle / Box box x, y, width, height, rotation Rectangular webcams, chat boxes, stream overlays
Custom Polygon polygon points: [[x, y], ...] Complex avatar silhouettes, hats, wings, props

🚀 Spawn Trajectories & Ballistics

When triggering a throw, configure spawn_direction:

  • aimed (Default): Solves ballistic trajectory equations to aim directly at target center, factoring gravity and distance.
  • rain: Drops items randomly across the top border with world gravity.
  • left, right, top, bottom: Launches from the chosen screen border toward the center.
  • random: Selects an offscreen edge at random.
  • spray: Spawns from a fixed origin coordinate (spawn_point) with an adjustable angle (spray_angle).

🔊 Low-Latency Web Audio Engine

Yeet includes an embedded Web Audio synthesizer that creates rich procedural impacts directly in OBS without loading external sound files:

  • Procedural Synthesizers: squish (triangle frequency sweep + filtered noise), bonk (resonant cartoon sweep), thud (low-frequency punch), pop (bubble pop chirp), clang (metallic dual-oscillator chime).
  • Dynamic Limiter: Master DynamicsCompressorNode prevents clipping or ear fatigue during barrages.
  • Pitch Randomization: Every hit alters pitch by $\pm$pitch_randomness so sounds stay dynamic.
  • Sound Debounce: Configurable sound_debounce_ms (default: 50ms) suppresses overlapping audio bursts.

📡 REST API Reference

The local daemon listens on http://127.0.0.1:49122. All endpoints accept CORS.

POST GET /api/v1/throw

Spawns throwable items with trajectory physics into the OBS overlay.

Query / JSON Body Parameters:

ParameterTypeDefaultDescription
itemstring"random"Item ID, "random", or "random_mix"
itemsstringnullCandidate items for mix: "all" or "tomato,pie,brick"
groupstringnullFilter candidate pool by group tag (e.g. "summer", "food")
item_excludestringnullExclude item IDs or groups (e.g. "construction,winter")
amountinteger1Projectile count (1 – 100)
spawn_directionstringconfigured"aimed", "rain", "left", "right", "top", "bottom", "random", "spray"
forcefloat1.0Velocity multiplier (0.1 – 5.0)
spreadfloat15.0Spread angle variance in degrees

Example 1: Single Throw (POST JSON)

curl -X POST http://127.0.0.1:49122/api/v1/throw \
  -H "Content-Type: application/json" \
  -d '{"item": "brick", "amount": 3, "spawn_direction": "aimed", "force": 1.2}'

Example 2: Quick Throw (GET Query String)

curl "http://127.0.0.1:49122/api/v1/throw?item=beachball&amount=5&spawn_direction=rain"
Random Mix Mode & Group Filtering Examples

When item=random_mix is used, each projectile is chosen randomly from the filtered pool:

Throw 6 items from the summer group:

curl "http://127.0.0.1:49122/api/v1/throw?item=random_mix&group=summer&amount=6"

Throw all items except construction (no bricks):

curl "http://127.0.0.1:49122/api/v1/throw?item=random_mix&items=all&group_exclude=construction&amount=8"

Throw all items excluding food and construction:

curl "http://127.0.0.1:49122/api/v1/throw?item=random_mix&items=all&item_exclude=food,construction&amount=10"
POST GET /api/v1/collision

Triggers an instant collision impact on a target without waiting for projectile flight delay. Plays sound with pitch variance, spawns particle burst, and registers in statistics.

# Direct slap with Cream Pie
curl "http://127.0.0.1:49122/api/v1/collision?target=VTuber+Head&item=pie&sound=squish"
GET /api/v1/collisions

Retrieves total collision count, breakdown by target, breakdown by item, and the recent log.

curl http://127.0.0.1:49122/api/v1/collisions

To reset counters to zero: POST /api/v1/collisions/reset

GET /api/v1/items

Returns all configured throwable items and their physical parameters. Supports ?group= filtering.

curl "http://127.0.0.1:49122/api/v1/items?group=summer"
GET POST /api/v1/targets

Get or dynamically update collision target boundaries.

curl http://127.0.0.1:49122/api/v1/targets
POST GET /api/v1/clear

Immediately despawns all active physics bodies from all connected OBS browser sources.

curl -X POST http://127.0.0.1:49122/api/v1/clear

⚡ Collision Webhooks & Barrage Engine

Yeet includes an intelligent barrage settling engine designed to notify external software (e.g. VTube Studio, VNyan, Lumia Stream, Home Assistant) without flooding your network:

  • First Hit URL: Dispatched immediately upon the very first impact of a throw (e.g. switch avatar expression to Dizzy or Hurt).
  • Barrage Debounce: Continuing impacts during the barrage will not spam duplicate webhooks.
  • Last Hit URL: Dispatched once no new impacts occur for the configured Settling Delay (default: 2.0s). Restores neutral expression or normal lights.

Supported URL Placeholders:

  • {target}: Target name (URL encoded, e.g. VTuber+Head).
  • {item}: Item name that made impact (e.g. Ripe+Tomato).
  • {hits}: Total collisions accumulated during the barrage.
  • {event}: first_hit or last_hit.

Example VTube Studio Integration:

First Hit URL: http://127.0.0.1:8001/vts/hotkey?id=Expression_Dizzy
Last Hit URL:  http://127.0.0.1:8001/vts/hotkey?id=Expression_Neutral

🔌 WebSocket Protocol (`/ws`)

OBS Browser Sources connect via ws://127.0.0.1:49122/ws.

  • init: Dispatches full configuration payload upon client connection.
  • throw: Commands the overlay to spawn projectiles.
  • collision: Commands an immediate impact burst and sound.
  • clear: Removes all rigid bodies.
  • targets_updated: Updates collider geometries in real time.
  • collision_event: Sent from OBS to server when physics bodies collide.
